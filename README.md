## Sobre

Plataforma enterprise que unifica observabilidade de TI e OT industrial, gestão de Active Directory, CMDB, alertas com impacto de negocio e um assistente de IA — tudo monitorando uma industria de laticinios ficticia com **333 ativos** e **250 usuarios** em Active Directory real.

## Cenario

**Laticinios Vale Verde S/A** — industria de medio porte, ~280 funcionarios, operacao 24/7 em 3 turnos. Matriz em Pouso Alegre/MG, filial comercial em Sao Paulo/SP. Produz leite UHT, queijos, iogurte e manteiga.

## Stack

**Backend:** Python 3.12 · FastAPI · SQLAlchemy · Alembic · PostgreSQL · Redis
**Frontend:** Next.js 15 · TypeScript · Tailwind · shadcn/ui · ECharts
**Observabilidade:** Prometheus · Loki · Grafana · AlertManager
**Infra:** Docker · Active Directory · ldap3 · WebSocket
**Integracoes:** Zammad · Taiga

## Modulos (MVP)

Dashboard NOC · Observabilidade TI · Observabilidade OT (OEE/HACCP) · Rede · Energia/Infra fisica · Active Directory · Impressoras · CMDB · Alertas · Automacao de chamados · IA para Infra
